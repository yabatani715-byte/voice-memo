使い方・注意

・文字起こしはブラウザ内蔵の音声認識を使うため 無料 ですが、精度は中程度です。ネット接続が必要です。
・iPhone では Safari で開き、画面を点けたまま録音してください（画面ロック・アプリ切替で停止します）。
・長い会議は数分ごとに区切って録音すると取りこぼしが減ります。
・整形／要約／翻訳は Claude API を使うため 従量課金 です（数十分の会議で数円〜数十円程度）。
・データはこの端末のブラウザ内にのみ保存されます。機種変更前にバックアップを書き出してください。
