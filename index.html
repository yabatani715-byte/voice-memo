使い方・注意

・文字起こしはブラウザ内蔵の音声認識を使うため 無料 ですが、精度は中程度です。ネット接続が必要です。
・iPhone では Safari で開き、画面を点けたまま録音してください（画面ロック・アプリ切替で停止します）。
・iOS は音声認識を数十秒で強制終了するため、重ね録りで切れ目を埋めています。それでも稀に取りこぼします。
・整形／要約／翻訳は Claude API を使うため 従量課金 です。長い文字起こしは自動で分割して処理します。
・データはこの端末のブラウザ内にのみ保存されます。ホーム画面に追加して使うと消えにくくなります。
