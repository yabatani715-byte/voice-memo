# 録音メモ

スマホで話した内容をその場で文字起こしし、Claude が整形・要約・翻訳する単一HTMLのWebアプリ。

- 文字起こし: ブラウザ内蔵の音声認識（Web Speech API）— 無料・APIキー不要
- 整形 / 要約 / 翻訳 / 自由指示: Claude API（各自のAPIキーを端末内に保存して使用）
- 録音を止めたら自動で整形・要約まで走らせる設定あり（設定タブ）
- 長い文字起こしは自動で分割し、抽出 → 統合の2段階で要約
- 音声ファイルの保存、検索、バックアップの書き出し／読み込みに対応
- データは端末内（IndexedDB / localStorage）にのみ保存され、Anthropic 以外へは送信されません

## 使い方

1. 公開URLを開く（マイクを使うため HTTPS 必須）。iPhone は Safari で開き「ホーム画面に追加」。
2. 「設定」タブで Claude の API キー（console.anthropic.com → API Keys）を登録。文字起こしだけなら不要。
3. 「録音」タブの丸ボタンで録音 → 「停止して保存」。
4. 保存後の画面で「要約する」などを実行（設定で自動実行も可）。

## 注意

- iOS は音声認識を数十秒で強制終了するため、認識器を重ねて起動する「重ね録り」で切れ目を埋めています。
- 録音中に画面を消す・他のアプリに切り替えると認識が止まります。
- Claude API は従量課金です。モデルは設定タブで Opus 5 / Sonnet 5 / Haiku 4.5 から選べます。
